# TechNova – College Fest Website

## About the Project

**TechNova** is a college fest website designed to provide information about the college's technical and cultural festival. It showcases event details, schedules, memorable moments, and contact information through a modern and responsive design.

The website is built using HTML and Tailwind CSS, with a dark theme and attractive visual elements.

## Pages Included

The website consists of five main pages:

### 1. Home Page

- Introduces the TechNova college fest.
- Displays a hero section with an attractive banner.
- Highlights important events and fest activities.
- Provides navigation to other website sections.

### 2. About Us Page

- Provides information about TechNova.
- Explains the purpose and vision of the fest.
- Highlights the college fest experience.

### 3. Schedule Page

- Displays the event schedule.
- Shows event names, dates, and timings.
- Helps visitors understand the fest activities.

### 4. Gallery Page

- Displays photographs from college events and activities.
- Includes moments from performances, workshops, competitions, and celebrations.
- Uses a responsive image grid layout.

### 5. Contact Page

- Provides contact information.
- Includes a contact form design.
- Helps visitors connect with the organizing team.

## Technologies Used

- **HTML5** – Website structure and content.
- **Tailwind CSS** – Styling, layout, and responsive design.

1. Download or clone the project.
2. Open the project folder in VS Code.
3. Open `index.html` in your browser.
4. Navigate through the five pages using the website navigation bar.
